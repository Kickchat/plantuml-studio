# PlantUML Studio

Нативный редактор PlantUML для macOS с локальным SVG-предпросмотром и структурным конструктором Sequence / Information Engineering ER / Component.

## Запуск

Репозиторий: https://github.com/Kickchat/plantuml-studio. Исходный код приложения распространяется по [MIT](LICENSE); лицензии bundled PlantUML/JRE перечислены в [зависимостях](docs/Dependencies.md).

Откройте `dist/PlantUML Studio.app`. Java и PlantUML находятся внутри приложения, сеть не нужна. Сборка для Apple Silicon; macOS 14+.

[GitHub Releases](https://github.com/Kickchat/plantuml-studio/releases) — установочные ZIP и канал автоматических обновлений. Следующие версии устанавливаются через «PlantUML Studio → Проверить обновления».


## Сборка

Требуется Xcode с macOS SDK. В этой среде проверены Xcode 27.0 и Swift 6.4.

Sparkle 2.10 загружается Swift Package Manager по зафиксированной версии и checksum (первое разрешение зависимости требует сети). Для локальной сборки без feed/public key автоматические обновления отключены; редактор работает локально. Версия и build задаются только в `Version.json`.

```sh
./scripts/build.sh
./scripts/build-dmg.sh # DMG с установкой в Applications
open "dist/PlantUML Studio.app"
```

Можно открыть `PlantUMLStudio.xcodeproj`, выбрать схему PlantUMLStudio и выполнить Build. Проект запускает тот же build.sh. Для редактирования Swift Package и тестов удобно открыть `Package.swift` в Xcode.

Runtime включён в историю проекта как зафиксированные сторонние зависимости. Если он отсутствует, выполните `./scripts/bootstrap-runtime.sh` (однократно требуется интернет).

## Проверка

```sh
./scripts/test.sh
./scripts/smoke.sh # после сборки, в графической сессии macOS
```

Тесты проверяют парсер, сохранность исходника, UTF-16/Unicode/CRLF, границы блоков, переименование, визуальные изменения, сохранение/открытие и реальный рендер SVG/PNG официальным PlantUML. Примеры находятся в `Fixtures`.

## Работа

- ⌘N — Sequence; ⇧⌘N — ER; ⌘O — открыть; ⌘S — сохранить; ⇧⌘S — сохранить как.
- ⌘Z / ⇧⌘Z — общие Undo/Redo для кода и конструктора.
- ⌘F / ⌘⌥F — поиск/замена с regex; ⌘⇧P — палитра команд; ⌘+/⌘−/⌘0 — масштаб. Пользовательские ⌘⌥ shortcuts доступны в Settings.
- Режим панелей и горизонтальное/вертикальное разделение находятся над редактором; масштаб — в заголовке диаграммы. Область диаграммы перемещается прокруткой либо Alt + перетаскиванием.
- Settings → Appearance: System / Light / Dark. Тема применяется ко всем окнам сразу и сохраняется между запусками; оформление пользовательской диаграммы определяется исходным `.puml`.
- Выберите элемент в списке конструктора или щёлкните его уникальную подпись в SVG. Измените свойства и нажмите «Применить». Переименование алиаса выполняйте отдельно от других полей.
- Меню «Добавить элемент» создаёт реальные конструкции. У блока можно добавить сообщения, вложенные блоки и ветвь else; у сущности — атрибуты и разделители.
- SVG / PNG экспортируются через меню File. Для неоднозначного документа задайте режим Sequence / ER или «Только текст».

Все файлы остаются обычным PlantUML. Конструктор изменяет конкретные диапазоны, проверяет результат официальным движком и сохраняет остальной исходник.

## Семантический конструктор v0.5

Участники, сообщения и ветви Sequence отображаются по названиям; ER — как сущности с атрибутами и отдельные связи. Поиск работает по объектам и сохраняет контекст вложенности. Свойства редактируются формами; операции перемещения, дублирования, удаления и добавления доступны в контекстных меню. ⌘ + щелчок поддерживает выбор нескольких объектов.

Выбор объекта показывает код и однозначно найденный элемент SVG; выбор в коде раскрывает соответствующую группу. При ошибке показывается последнее корректное дерево, а изменение через формы блокируется. Зависимые сообщения и связи удаляются только после подтверждения.

«Настройки диаграммы» содержит название, простую автонумерацию и поддерживаемые параметры оформления. Неизвестные параметры сохраняются. Кнопка правой панели скрывает конструктор, разделители меняют ширину панелей и высоту свойств; меню масштаба содержит Fit to Window / Fit to Width. Подробности: [проверка и ограничения v0.5](docs/Release-v0.5.md), [ТЗ](docs/Requirements-Semantic.md).
