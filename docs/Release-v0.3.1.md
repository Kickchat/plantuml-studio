# PlantUML Studio 0.3.1 — оформление и темы

Ветка: `feature/appearance-redesign`, основана на `release/v0.3`.

## Изменения

- Settings → Appearance: System, Light, Dark; немедленное применение ко всем окнам. Предпочтение хранится в стабильном ключе UserDefaults `studio.appearance.mode`, без номера версии. По умолчанию System; неизвестное значение также возвращает System.
- System снимает принудительный appearance приложения и наследует macOS. AppKit и SwiftUI обновляют нативные представления; NSTextView и WKWebView дополнительно обрабатывают изменение effectiveAppearance.
- Общая палитра, семантические цвета и размеры вынесены в модуль StudioDesign. Основа: navy `#172332`, forest `#086B50`, mint `#73E5BB`, soft white `#F7F9F8`, light gray `#E9EFED`. Вторичный текст затемнён в Light для контрастности; фон выделения приглушён.
- Компактные вкладки и toolbar, отдельные заголовки кода и диаграммы, масштабирование возле preview, тонкие разделители, единое оформление Outline, Properties, поиска, Command Palette, шаблонов, истории и Diff.
- SF Pro для интерфейса, SF Mono для кода. Синтаксис различает фиолетовые ключевые слова, синие объявления участников, зелёные сообщения, янтарные строки и нейтральные комментарии. Оформлены активная строка, курсор, выделение, ошибки и номера строк.
- Короткая анимация смены панелей отключается при Reduce Motion. Стандартные меню и состояния элементов используют нативное поведение macOS.
- Тема меняет только цвета атрибутов редактора и фон оболочки preview. HTML/SVG не перезагружается из-за темы; исходный SVG сохраняется, область диаграммы имеет неизменный светлый бумажный фон. Явные цвета пользовательского `.puml` остаются прежними.
- Исправлено перекрытие кода линейкой при overlay scrollers: viewport резервирует ширину номеров строк, отрисовка линейки ограничена её границами.

Парсеры, операции конструктора, рендерер, история документов и модель Undo/Redo не изменены. Новый логотип продолжает использоваться как иконка приложения.

## Проверка

- 58 XCTest без ошибок, включая реальные SVG/PNG через bundled PlantUML. Новые проверки: сохранение предпочтения, System/Light/Dark resolution, fallback и контраст текста не менее 4.5:1 на соответствующих поверхностях Light/Dark.
- GUI smoke: мгновенная смена темы в двух окнах; соответствие фона WKWebView; сохранение текста, SVG DOM, dirty, selection, scroll, доступности Undo/Redo и самих native views. Проверяется отсутствие перекрытия кода линейкой.
- Нативная смена appearance в System моделируется на уровне NSApplication, пока сохранённый режим остаётся System. Настройки macOS пользователя не изменяются. Реальное переключение ОС через System Settings отдельно не автоматизировано.
- Снимки ER, Component, Diff, Command Palette, Templates и History в Light/Dark находятся в `.build/Smoke`. Settings также участвует в проверке двух окон.
- Release `.app` собирается через build.sh и Xcode wrapper; подпись ad hoc проверяется codesign. Приложение для Apple Silicon, macOS 14+.

## Где смотреть

`dist/PlantUML Studio.app` — готовая версия 0.3.1. Для воспроизведения: `./scripts/test.sh`, `./scripts/build.sh`, затем `./scripts/smoke.sh` в графической сессии macOS.
