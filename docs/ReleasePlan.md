# План v0.2 / v0.3

База v0.1: commit 6be7de7. Рабочая ветка v0.2: release/v0.2. Git был инициализирован, поскольку исходная папка не содержала репозитория. Основная ветка не сливается автоматически.

Официальный гайд отдельным файлом не приложен; продолжается ранее согласованное использование plantuml.com (sequence-diagram, ie-diagram, component-diagram).

v0.2: расширить Core навигацией, поиском, безопасными быстрыми операциями и форматированием; добавить локальный каталог шаблонов; развить существующие Constructor/Editor/Preview/Document, Command Palette и настройки shortcuts; улучшить отмену процессов; регрессия v0.1, новые тесты, измерения 100/300/500/1000 строк, запуск .app. После этого commit v0.2.

v0.3: отдельная ветка от завершённой v0.2; ComponentModule на общем SourceDocument и Renderer; текстовый и структурный Diff с обозначением неоднозначности; сравнение источников и SVG рядом; локальная ограниченная история версий; Component-шаблоны; тесты и отдельный commit. Слияние только после подтверждения пользователя.

Фактические ограничения v0.1: подмножество грамматики, запрет небезопасных изменений неизвестных ссылок, SVG-сопоставление только при уникальном признаке, неотменяемый запущенный Java-процесс (устаревший результат лишь игнорировался). Эти ограничения учитываются при расширении, исходник не регенерируется.

Итог: v0.2 commit af778f6, release/v0.3 разработана отдельно и проверена 55 тестами, release Xcode build, GUI smoke и codesign verification. В .build/Smoke есть снимки финального интерфейса. В main ничего не слито. Текущая иконка берётся из предоставленного Assets/image.png; прежний файл остаётся в истории v0.2.
