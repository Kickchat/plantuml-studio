# PlantUML Studio v0.2

Ветка release/v0.2 от базы 6be7de7. Слияние в main не выполнено.

Добавлены дерево блоков / сущностей с раскрытием, поиск структуры, синхронизация курсора и выбора, множественный выбор, контекстные операции (ответ, до/после, дублирование, обёртки alt/opt/loop, перемещение), пакетные атрибуты и связь двух выделенных сущностей через палитру. Поиск/замена поддерживает case, regex, captures, prev/next, replace/all. Палитра ⌘⇧P фильтрует доступные команды; стандартные клавиши и назначаемые ⌘⌥-команды в Settings.

11 локальных шаблонов, пользовательские шаблоны в UserDefaults, проверка контекста и безопасное разрешение конфликтов идентификаторов. Editor: native completion через Escape/контекстное меню, автоматические закрытия, подчёркивание пар, скрытие тела блока, форматирование только выделения (отступы распознанных строк), переход к диагностике. Preview: fit window / width, zoom/reset, pan Alt/middle, возврат к выделению, сохранение позиции при обычном обновлении, подчёркивание только однозначного SVG-совпадения.

Разбор и рендер вынесены с main actor; debounce 350 мс; отмена устаревшего процесса; bounded cache и очередь. Incremental identity reconciliation, без инкрементального рендера: PlantUML принимает целую диаграмму.

Проверка: 39 XCTest прошли (включая реальные SVG/PNG, 11 шаблонов, отмену работающего Java), release-сборка и GUI smoke прошли. GUI smoke проверяет открытие поиска/палитры, template+undo и регрессию v0.1; это не полное покрытие клавиатурных действий XCTest UI.

Замеры: macOS 26.6, Apple Silicon arm64, release, bundled JRE21/PlantUML1.2025.0, один запуск на размер, Sequence с двумя участниками и уникальными сообщениями. Подробные реальные значения: Performance-v0.2.json. Parse 1.29–3.86 мс (100 строк первый запуск 1.47), cold render 871–1162 мс, source operation 0.054–0.902 мс (без последующей render-validation), cached render 0.043–0.109 мс. Это не статистический benchmark и не ER/смешанная нагрузка.

Ограничения: остаётся подмножество грамматики v0.1. Неизвестные конструкции сохраняются и блокируют небезопасное изменение ссылок. SVG с одинаковыми подписями не выбирается произвольно. Сворачивание скрывает glyphs и сокращает высоту строк, не меняя исходный текст; любой ввод разворачивает блоки. Форматирование меняет только отступы распознанных строк, не форматирует неизвестные конструкции и closing markers. Глобальный rename отказывается от неизвестных ссылок. Пользовательские shortcuts имеют фиксированные ⌘⌥ modifiers. Диалог шаблонов хранит данные локально; пользовательский фрагмент проверяется перед вставкой.

Ваш PNG Assets/PlantUML App Icon.png используется для сборки AppIcon.icns, исходный файл сохранён без изменений.
