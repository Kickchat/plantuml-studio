# Матрица синтаксиса

Источники, согласованные пользователем:

- https://plantuml.com/en/sequence-diagram
- https://plantuml.com/ie-diagram
- https://plantuml.com/class-diagram
- https://plantuml.com/smetana02

Проверяемый движок: PlantUML 1.2025.0. «Сохраняется» означает побайтовую сохранность исходного текста при незатрагивающей операции; неизвестные строки не сериализуются заново. Это матрица реализованного подмножества, не полный список возможностей PlantUML.

| Конструкция | Чтение / свойства | Создание и удаление | Порядок |
|---|---|---|---|
| actor, participant, boundary, control, entity, database, collections, queue | Название, тип, алиас; две формы `"Label" as A` и `A as "Label"`; присутствующие цвет, стереотип и order | Да; удаление декларации с внешними ссылками запрещено | Между соседями без пересечения комментариев |
| Sequence `->`, `-->`, `->>`, `-->>`, `<-`, `<--`, `<<-`, `<<--`, `<->`, `->x`, `o->`, `->o` | Концы, стрелка, текст; self-message | Да | В одной ветви, без пересечения активаций |
| alt, opt, loop, par, break, critical, group | Условие/подпись, вложенность, полный диапазон | Да; вложенные блоки и сообщения внутри, else для alt/par | В пределах родительской ветви |
| else | Подпись | Кнопка у alt/par; отдельное удаление заблокировано | Граница ветви |
| activate, deactivate, destroy | Тип и участник | Да, после проверки движком | Визуальное перемещение запрещено |
| Однострочный note left/right/over | Положение, участник, текст | Да | Между соседями |
| Многострочный note … end note | Положение, участник, тело | Чтение, изменение и удаление; создание через код | Между соседями |
| title и title … end title | Текст, многострочное тело | Однострочное создание, оба вида удаляются | Между соседями |
| autonumber | Присутствующие параметры | Да | Между соседями |
| `== label ==`, `... label ...` | Текст | Да | Между соседями |
| ER entity … { … } | Название, алиас, присутствующие стереотип/цвет | Да | Между соседями |
| ER атрибут | Имя, присутствующий тип, обязательность `*`, стереотип | Да; метка `<<PK>>`, разделитель `--` | Только внутри той же сущности |
| IE связь | Исходная/целевая сущности, подпись, `--` / `..` | Да | Между соседями |
| Кардинальности | Слева `||`, `|o`, `}o`, `}|`; справа `||`, `o|`, `o{`, `|{` | Все 16 пар; проверка официальным движком | — |
| Неподдерживаемые формы стрелок, shortcut-активации, return, skinparam, ref, стили, препроцессор | Сохраняются, рендерятся при допустимости в локальном SECURE profile | Редактирование через код | Визуальное пересечение неизвестных строк запрещено |

`*` в Information Engineering означает обязательный атрибут. `<<PK>>` и `<<FK>>` — визуальные стереотипы; они не создают ограничений БД.

Переименование алиаса обновляет только распознанные ссылки и отклоняется при неизвестной ссылке или note, использующем это имя. Нестандартные/кавычечные идентификаторы можно редактировать в коде. Цвет может быть добавлен кнопкой и затем изменён. Stereotype, order и тип данных доступны в свойствах, когда соответствующие токены уже присутствуют; добавление отсутствующих дополнительных токенов выполняется кодом.
