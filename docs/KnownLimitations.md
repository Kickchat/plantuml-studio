# Известные ограничения

- Собранный Runtime — Apple Silicon. Минимальная версия приложения macOS 14; фактический запуск проверяется на доступной macOS 26. Intel требует отдельного JRE и сборки.
- Поддерживается описанное в SupportMatrix.md подмножество. Неизвестные конструкции остаются в коде; это не полный парсер языка PlantUML.
- Один @startuml/@enduml в документе. Сохранение файла с несколькими диаграммами доступно, конструктор блокируется.
- Визуальное переименование алиасов с неизвестными ссылками/note блокируется; кавычечные имена без алиаса переименовываются в коде.
- Перемещения через комментарии, активации, неизвестные строки и границы ветвей запрещены. Это сознательное ограничение, сохраняющее семантику и привязку комментариев.
- Выбор в SVG работает для уникального текста/имени и ER-сущностей. Повторяющиеся подписи, сообщения без текста и стрелки выбираются через структурный список.
- Состояние вкладок сохраняется при штатном закрытии/выходе. Полного восстановления после аварии и внешнего file watcher пока нет.
- SECURE profile исключает сетевые include/внешние ресурсы; документы, которым они нужны, редактируются текстом с диагностикой.
- Smetana может давать раскладку, отличающуюся от Graphviz. Ограничение рендера — 15 секунд и 256 МБ heap; в кэше не более 32 МБ.
- Диагностика редактора подсвечивает строку, если официальный движок сообщил её номер. Парсер сообщает структурные ошибки отдельно.
- Xcode-проект использует legacy build target, запускающий воспроизводимую Swift Package сборку. Unit/integration tests запускаются scripts/test.sh или из открытого Package.swift, а не legacy target.
- Полный кликовый UI-сценарий не автоматизирован. scripts/smoke.sh запускает реальное окно, проверяет конструктор, редактор, Undo/Redo, сохранение, ER, SVG/PNG и создаёт снимки; пользовательские диалоги и жесты дополнительно проверяются вручную.

v0.2/v0.3 расширяют эту базу; актуальные ограничения folding/format/shortcuts, Component grammar, консервативного diff и history перечислены в Release-v0.2.md / Release-v0.3.md. Общая прокрутка текста в diff обеспечена одним viewport; SVG имеют общий масштаб и независимую прокрутку. History retention — на файл, не общий размер всех файлов.
